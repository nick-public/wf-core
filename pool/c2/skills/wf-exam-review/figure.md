# 그림 — 시험지 crop과 수학 그래프

## A. 시험지 캡처에서 그림 영역만 잘라 원문에 붙이기
- 원본 캡처는 절대 고치지 않는다. crop은 캡처 폴더 아래 `figs/`에만, 이름은 `Q<번호>_<설명>.jpg`(공백은 `_`).
- 원문 텍스트화 파일에서 그 문항이 원본의 몇 쪽인지 먼저 찾는다.
- 좌표를 받지 못하면 Claude가 추정한다: 시험지는 보통 2단 → 좌/우단, 문항 번호 위치로 위아래, 이미지 크기 비율로 픽셀 환산. 추정 정확도는 ±10% 정도라 **잘라 낸 결과를 반드시 Read로 보고** 미세 조정한다(덮어쓰기). 추정 좌표는 사용자에게도 한 줄로 알린다.
- EXIF 회전된 사진이 많다: `ImageOps.exif_transpose()`를 먼저 적용한다. 결과가 500KB를 넘으면 `quality=85` 또는 축소.
- 여러 줄 Python은 `python -c`로 쓰지 말고 scratch에 `.py` 파일로 쓴다(인자: 원본 · 좌표 · 출력).
- 원문 파일의 그 문항 아래, 기존 `[FIG: …]` 자리표시 줄 **위**에 원문 파일 기준 상대 경로의 이미지 링크(`![Q16 좌표평면](<캡처 폴더>/figs/Q16_좌표평면.jpg)`)를 넣는다(자리표시는 지우지 않는다). OCR 이슈 목록에 그 항목이 있으면 닫음 표시.

## B. 수학 그래프를 네이티브로 (풀이 앱의 캡처 이미지를 대체)
**언제 반드시:** 원본에 그림 · 그래프 · 좌표가 있다(`![…]` · `[FIG:]`), 함수 그래프 서술(꼭짓점 · 교점 · 접선 · 넓이 · 최대최소), 파라미터가 변하며 점 · 도형이 움직인다, 좌표평면 위 기하. 그림 없는 대수 문제라도 함수 · 좌표가 핵심이면 권장.

**형식 고르기**
| 화면 | 형식 | 금지 |
|---|---|---|
| page-0 문제 | 정적 SVG — 원본 구도 · 라벨(O, A, B…), 대표값(예: m=1) 위치로 고정 | 보드 · 슬라이더 · 눈금 숫자 |
| 풀이 단계 | JSXGraph 보드(슬라이더로 파라미터 탐구) | 그 단계 전에 도출되지 않은 정보 |
| 연습 앱 | 작은 정적 SVG(정성적 개형만) | 보드 · 슬라이더 |

**JSXGraph 함정:** 숨겨진 페이지의 div에서 보드를 초기화하면 렌더가 실패한다 → 그 단계로 처음 이동할 때 한 번만 만든다.
```javascript
let _boardInit = false;
function goTo(n) {
  /* … 페이지 전환 … */
  if (n === 1 && !_boardInit) { initBoard(); _boardInit = true; }
}
```
CDN은 cdnjs의 고정 판(예: `jsxgraph/1.11.1`)을 쓴다. 보드 옵션은 `showNavigation:false, showCopyright:false`. 동적 점 · 텍스트는 슬라이더 값의 함수로 만든다.

**색:** 함수 `#4361EE`, 최소 · 기준점 `#22c55e`, 최대 · 강조점 `#ef4444`(풀이 앱과 같은 팔레트).

슬라이더 · 애니메이션은 헤드리스 결과만으로 통과시키지 않는다 — pool의 화면 시험(wf-ui-qa)으로 실제 조작을 본다.
