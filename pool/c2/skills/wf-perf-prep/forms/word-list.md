# 단어 암기 — 단어 · 표현 목록 공개 + 뜻 · 빈칸 · 영작 시험

공지의 목록을 전부로 보고 시작한다(목록 밖을 늘리지 않는다). 정본은 목록 데이터 파일 하나(단어 · 뜻 · 예문 · 해석).

## 앱 (권장 모양)
- 탭은 셋 안팎: **시험 유형별 전체 시트**(목록 전체를 뜻 · 빈칸 · 영작 등 실제 시험 유형마다 한 장씩) · **시험지**(한 페이지에 20문항 정도를 쭉 나열하고 채점은 한 번, 전체 문항 풀에서 랜덤 재출제, 문항에 유형 태그) · **표시한 것**.
- 틀린 문항은 자동 표시. 아이가 직접 표시 / 해제. 표시한 것만 추려 보기가 핵심 기능이다.
- 모르는 것을 확인할 방법이 있어야 한다: 문항마다 정답 보기 토글(정답 · 단어 · 예문 · 해석을 함께), 본 문항은 자동 표시.
- 뜻 채점은 부분 일치 + 자가 판정(맞음 / 틀림), 영작은 모범 문장과 자가 대조.
- 유형별 드릴 · 암기 점검 · 날짜별 플랜은 넣지 않는다(사용자: 불필요, 언제 끝날지 알 수 없으면 안 쓴다).
