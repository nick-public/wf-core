# 체크리스트 논술 — 채점 체크리스트 사전 공개 + 손글씨 서술

목표: 체크리스트 항목마다 요구 키워드가 들어간 완전한 문장을 아이가 손으로 쓸 수 있게. 계산 · 자료해석이 섞여 있어도 최종 형태가 서술이면 이 판. 약점은 보통 키워드 누락 · 근거 없는 답 · 중간 계산 생략.

## 정본 (순서대로)
1. `10_prep/01_answer_keys.md` — 항목마다: 대표 소문항 2개 · 모범 문장 틀(1~3문장, 키워드 굵게) · 필수 키워드 3~5(교과서 문장에서) · 감점 포인트(아이 흔적의 실제 실수 + 일반 실수) · 같은 뜻의 변형 질문.
2. `10_prep/02_mock_bank.md` — 시나리오 = 자료에서 실제로 본 실험 · 자료 형태. 시나리오마다 소문항을 체크리스트 항목에 **1:1**로. 소문항마다 문항 · 배점 · 모범답안 · 키워드 채점표(체크박스) · 부족할 때 돌아갈 카드. 숫자는 자료의 실제 수치 우선. 수업 실험 조건처럼 확인이 필요한 값은 두 경우를 다 덮는 대비 문장을 넣는다.
3. `10_prep/03_drill.md` — 아이 흔적에서 확인된 약점만, 10문 안팎 즉시 채점 단답, 풀이는 절차 한 줄. 부수 표(지시약 · 생활 사례 등)도 여기.

## 앱 (경량, Canvas · KaTeX 없음 — 첨자는 유니코드)
카드(뒤집기) · 실험 시뮬(SVG, 필요할 때만) · 드릴(랜덤 · 즉시 채점 · 되풀이) · 모의(타이머 → 종이에 쓰기 → 모범답안 공개 → 키워드를 아이가 체크 → 점수 → 카드로) · 전날 점검.

## 프린트 팩
카드 → 모의 문제 쪽 → (별도 쪽) 답안 · 채점표 → 드릴. 답안 쪽을 문제 쪽과 떼어 문제만 먼저 보게 한다.
