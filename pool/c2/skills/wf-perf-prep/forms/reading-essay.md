# 독서 논술 — 문항 사전 공개 · closed-book · 원고지 분량 제한

목표: 문항마다 사실이 정확하고 이유가 붙은, 분량 범위 안의 답안을 외워서 제한 시간 안에 원고지에 쓰게. 약점은 보통 분량 미달 · 초과, 시험 범위 밖 내용 중심, 연도 · 인물 사실 오류, "이유" 누락, 진로 · 가치관 문항의 구체성.

## 정본
1. `00_reading_guide.md` — 아이가 책을 읽기 **전에** 보낼 메신저 본문 한 덩어리: 문항을 머리에 두고 읽기 → 인상 깊은 문장 3~5개 표시 · 사진 → 다 읽고 짧은 질문 몇 개에 한 줄 답(요약 · 장면 · 느낌 · 진로 연결 유무 · 쪽 범위). 시험 범위 주의 한 줄. (보내는 것은 사용자가 한다.)
2. `01_chapter_digest.md` — 제목이 던지는 물음의 답(주제 사슬) → 연표(시험 범위 안 사건 표시) → 인물 관계 → 교과서 용어 · 흔한 혼동 → 평가가 갈리는 지점(중립) → 문항별 재료 배분. 통설로 초안을 쓰되 "책 대조" 칸을 두고, 사진이 오면 **책의 서술 · 표현을 우선**해 확정.
3. `02_answer_keys.md` — 문항마다 1) 문항 분해 2) 채점 포인트 추정(분량 · 사실 · 이유 · 구체성) 3) 뼈대 5줄 4) 모범답안 A(만점형) 5) 모범답안 B(압축형, 시간이 밀릴 때) 6) **글자 수 실측**(A · B 각각 공백 포함 / 제외를 `len()`으로 — 어느 방식으로 세어도 범위 안이 되게) 7) 사실 체크(A · B의 연도 · 인물 · 지명이 digest에 있는지 하나씩) 8) 감점 포인트.
   - 인용 문항: 인용은 **사진 원문 그대로**. 원문이 아직 없으면 "장면 소개"형으로 쓰고 나중에 교체.
   - 진로 · 가치관 문항: 아이 답의 각도 1 + 진로와 무관한 각도 2(선택 · 전문성 · 기억 등). 아이가 연결 없음이라 하면 잇지 않는다.
   - 각도가 둘 이상 가능한 문항은 A를 각도별로 두고 아이가 고른다.
4. `03_honest_guide.md` — 앱 시작 탭 원문: 채점 구조(기본 점수 → 변별 점수) · 감점 함정 · 시간 배분표 · 원고지 규칙(띄어쓰기 · 문장부호 한 칸, 첫 칸 들여쓰기) · 암기법(뼈대 → 문장, 하루 10분 × 3일) · 시험장 요령. 아이에게 말하는 톤, 과장 · 훈계 없음.
5. `04_fact_quiz.md` — 12~15문, 답안에 실제로 나오는 연도 · 지명 · 인물 · 주체만, 혼동 지점 집중, 해설 한 줄.

## 앱 탭
시작(시험 카드 · 가이드 · 일정) · 한눈에(주제 사슬 · 연표 · 실제 지도 · 인물) · 답안 카드(뼈대 → [A] [B], 가리기 토글, 인용 빈칸 채우기) · 원고지 연습(문항 → 타이머 → 타이핑 → 실시간 글자 수 공백 포함/제외 + 범위 색 경계 + 원고지 그리드 미리보기 → 모범답안 대조 → 키워드 체크 → 점수) · 사실 퀴즈(즉시 채점 · 되풀이) · 전날 점검.

## 프린트 팩
뼈대 카드 → 답안 A · B → 연표 1쪽 → **원고지 양식**(CSS grid, 문항 원문을 위에 인쇄, 문항당 두 회분) → 가이드 1쪽.

## 첨삭
손글씨 사진이 오면: 자료 폴더에 등재 → 칸 수 실측 → 뼈대 키워드 대조 → 사실 오류 → 이유의 설득력 · 흐름 → 글씨 판독 → 세션 로그에 첨삭, 정본 보정, 재빌드.
